Unstable collection、ImmutableList 與 strong skipping

這一題測試你能否把「型別 stability」與「參數比較方式」分開推理，而不是把 stable 直接等同於永遠 skip。

情境：相同內容，不同 List instance

List<User>ImmutableList<User>strong skipping
@Composable

    UserRows(users)
}

// Parent recomposes for an unrelated state change.
// Kotlin 2.0.20+ strong skipping is enabled.
val nextUsers = users.toList() // new List instance, same elements

若分別把參數宣告為標準 List<User> 與 Kotlinx ImmutableList<User>，哪個描述最精確？
